# Reminder Bot

Telegram-бот, который хранит важные даты (дни рождения, экзамены, дедлайны) и напоминает о них заранее. Каждый пользователь видит только свои события, а время напоминания выбирает сам.

Учебный проект по Python. Написан на pyTelegramBotAPI.

## Возможности

- добавление события по шагам: название, дата, за сколько дней напомнить, тип;
- три типа событий: обычное, день рождения, экзамен;
- просмотр и удаление своих событий;
- автоматические напоминания в фоновом потоке;
- понятные сообщения об ошибках вместо падения программы.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | показывает подсказку |
| `/add` | добавляет событие (бот задаёт вопросы по шагам) |
| `/list` | показывает все твои события с номерами |
| `/delete НОМЕР` | удаляет событие, например `/delete 3` |


## Установка

Нужен Python 3.9 или новее.

```bash
git clone https://github.com/ТВОЙ_НИК/reminder-bot.git
cd reminder-bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка

1. Создай бота в Telegram через @BotFather командой `/newbot` и скопируй токен.
2. Скопируй файл `.env.example` в `.env`.
3. Впиши токен в `.env`:

```
BOT_TOKEN=123456:ABC-твой-токен
```

Файл `.env` добавлен в `.gitignore` и не попадает в репозиторий.

## Запуск

```bash
python main.py
```

Бот отвечает и присылает напоминания, пока программа запущена. Остановить: `Ctrl+C`.

## Тесты

```bash
python -m pytest
```

Тесты проверяют разбор дат, логику напоминаний, хранилище и отправку напоминаний.

## Структура проекта

```
reminder-bot/
├── main.py              # точка входа: запуск бота
├── bot/
│   ├── handlers.py      # обработчики команд Telegram
│   └── reminders.py     # фоновая проверка и отправка напоминаний
├── core/
│   ├── models.py        # класс Event и наследники Birthday, Exam
│   ├── storage.py       # Storage и JsonStorage (хранение в JSON)
│   ├── dates.py         # разбор и проверка дат и чисел
│   └── exceptions.py    # собственные исключения
├── tests/
│   └── test_core.py     # тесты pytest
├── requirements.txt
└── .env.example
```

Папка `core/` ничего не знает о Telegram, поэтому её легко тестировать. Папка `bot/` отвечает только за общение с пользователем.

## Ограничения

- События хранятся в файле `data.json` рядом с программой.
- Напоминания приходят, только пока бот запущен.
- Если перезапустить бота в день напоминания, оно может прийти повторно.
